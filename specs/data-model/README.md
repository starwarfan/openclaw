# 全局数据模型

本目录包含跨模块的全局数据模型文档，描述核心实体、DTO、枚举和关系。

## 内容

- `schema.md` — 全局 Schema 概览
- `entities.md` — 核心实体定义
- `dto.md` — 数据传输对象
- `enums.md` — 枚举类型定义

## 与模块数据模型的关系

- 全局数据模型定义跨模块共享的类型
- 模块特有的数据模型在 `specs/modules/<module>/data-model.md` 中定义
- 全局类型变更需评估对所有依赖模块的影响
