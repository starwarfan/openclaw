# 编码规范

本目录包含项目的编码规范文档，为所有开发者和 AI Agent 提供一致的代码风格指导。

## 内容

- `naming.md` — 命名规范（变量、函数、类、文件等）
- `patterns.md` — 设计模式与最佳实践
- `package-structure.md` — 包/模块组织结构规范
- `testing.md` — 测试规范与约定

## 适用范围

- 所有新代码必须遵循本目录中的规范
- AI Agent 生成代码时应参考此目录
- 规范更新需经团队 review 后生效

## 主要参考

项目级编码规范主要定义在根目录 `AGENTS.md` 中：

- TypeScript 规范：见 "Coding Style & Naming Conventions"
- 测试规范：见 "Testing Guidelines"
- 提交规范：见 "Commit & Pull Request Guidelines"
